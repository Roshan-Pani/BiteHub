## 💡 Implementation Notes

To change the palette, update these variables in `src/Styles/index.css`:

```css
:root {
  --brand-900: [Primary Dark Color];
  --brand-600: [Primary Medium Color];
  --accent-600: [Accent Primary Color];
  --accent-200: [Accent Light Color];
  --text-primary: [Text Color for Light Backgrounds];
  --text-secondary: [Text Color for Dark Backgrounds];
}
```

All semantic classes will automatically inherit the new colors!
